# Abliterated Qwen3.8-27B in GPTQ INT4 on September 13, 2026

This is source research, not an Experiment. No checkpoint was downloaded, no model comparison ran, and no server configuration changed. The recommendation concerns compatibility with this server. Published evidence does not establish a best abliterated checkpoint for coding quality.

## Recommendation

Evaluate [kernelogic/Qwen3.8-27B-Uncensored-GPTQ-Int4-sym-G128-MTP-BF16](https://huggingface.co/kernelogic/Qwen3.8-27B-Uncensored-GPTQ-Int4-sym-G128-MTP-BF16) first. It matches the stored GPTQ INT4 format and has published Intel Arc Pro B70 deployment evidence using this repository's exact pinned XPU image, `sha256:f01e24f6c7ff01f1e0662234255a1372297d1dbd89d003cf13c8fad3eab1ba4f`. Its source is JonathanColetti's abliterated BF16 checkpoint. The publisher explicitly reports no quantized coding, reasoning, perplexity or refusal-rate evaluation. This supports a deployment recommendation, not a claim that it retains more capability than the alternatives.

JonathanColetti's BF16 source uses Heretic with 200 optimization trials. The author reports refusals falling from 98/100 to 12/100 on held-out prompts in non-thinking mode and a mean decrease of approximately 0.5 percentage points across four zero-shot capability benchmarks. The author did not evaluate generative coding, math, vision or MTP in those benchmarks. These measurements do not establish the GPTQ derivative's quality or refusal behavior with this server's xhigh thinking default. [Source model and evaluation](https://huggingface.co/JonathanColetti/Qwen3.8-27B-Uncensored#measured-behaviour)

The model card's runtime recipe uses a BF16 MTP draft. This repository's current `a-int4draft` profile applies INT4 quantization to the draft at runtime. BF16 MTP tensors in a checkpoint describe the stored weights, not necessarily their active runtime precision. A future experiment must test the candidate with the actual profile and measure MTP acceptance. Do not assume an exact file-format match is a validated model swap. [Current state](../../STATUS.md), [candidate serving recipe](https://huggingface.co/kernelogic/Qwen3.8-27B-Uncensored-GPTQ-Int4-sym-G128-MTP-BF16#serving-vllm-xpu)

Do not copy the candidate's entire serving command. Its instruction to disable prefix caching conflicts with this repository's validated cache configuration, and its `--language-model-only` flag disables vision. The evidence that matters here is the checkpoint and B70 deployment, not every setting in the publisher's recipe. [Current state](../../STATUS.md), [publisher recipe](https://huggingface.co/kernelogic/Qwen3.8-27B-Uncensored-GPTQ-Int4-sym-G128-MTP-BF16)

Safetensors is the file container. GPTQ, compressed-tensors packing, group size and mixed precision determine which inference kernels can load its weights. The repository names alone are insufficient to determine an exact match. This search establishes several available candidates, not an exhaustive inventory or a universal quality ranking.
