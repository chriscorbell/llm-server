# 2026-09-12 FP8 KV with the INT4 draft

Status: in progress
Profile: a-int4draft, original pinned image, MTP4

## Hypothesis

FP8 KV can increase cache capacity while preserving the current INT4 draft's coding, reasoning, tool and vision behavior at a 98,304-token window.

## Configuration

Change only the cache dtype from `auto` (FP16 with the current model dtype) to `fp8`. Keep context 98,304, GPU utilization 0.95, batched tokens 8,192, one sequence, vision, INT4 draft and MTP4. The engine remains pinned to `sha256:f01e24f6c7ff01f1e0662234255a1372297d1dbd89d003cf13c8fad3eab1ba4f`.

```bash
# On mbp, commit and push the parameterized compose file first.
ssh vllm 'cd ~/Code/llm-server && git pull --ff-only'
ssh vllm 'cd ~/Code/llm-server && KV_DTYPE=fp8 bash scripts/compose.sh --profile a-int4draft up -d --no-deps vllm-a-int4draft'
# Rollback:
ssh vllm 'cd ~/Code/llm-server && KV_DTYPE=auto MAX_MODEL_LEN_BF16KV=98304 bash scripts/compose.sh --profile a-int4draft up -d --no-deps vllm-a-int4draft'
```
